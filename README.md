# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:16-11-2026

## AIM: 
To create a 3D solid model of the given square base with four corner pillars and 
generate its orthographic (Front and Top) and isometric views using CAD modeling 
software. 
## REQUIREMENTS: 
* Operating System: Windows 10 / 11 (64-bit) 
* Processor: Intel Core i5 or higher 
* RAM: 8 GB minimum (16 GB recommended) 
* Graphics: Dedicated GPU (2 GB VRAM or higher) 
* Software: CAD Modeling Software (SolidWorks / Creo Parametric / AutoCAD / 
Fusion 360)
## PROCEDURE:
Step 1: Initialize the Workspace 
*Open the CAD software on your system. 
*Select the Top Plane and click Sketch. 
* Click File > New and select Part (3D Modeling workspace), then click OK. 
*Set the measurement unit system to MMGS (Millimeter, Gram, Second).

Step 2: Create the Base Plate 
* Choose the Center Rectangle (or Corner Rectangle) tool and draw a rectangle  
starting from the origin. 
*Use the Smart Dimension tool to set both the length and width to 30 mm. 
*Exit the sketch and go to the Features tab. 
* Select Extruded Boss/Base, set the extrusion depth (thickness) to 2 mm, and click 
OK.

Step 3: Create the Four Corner Pillars 
*Select the top flat face of the 30 × 30 mm base plate and click Sketch. 
* Select the Corner Rectangle tool and draw four small squares at each of the four             
inner corners of the base plate. 
* Use the Smart Dimension tool to set the length and width of each square to 2 mm ×        
2 mm (or dimension one square and apply an Equal relation to the remaining three). 
* Exit the sketch and select Extruded Boss/Base. 
*Set the extrusion height to 30 mm (upward from the top face of the base) and click 
OK.

Step 4: Generate 2D Orthographic & Isometric Views 
* Save the 3D part file . 
* Go to File > Make Drawing from Part and choose an A4 Landscape sheet format. 
* From the View Palette, drag and drop the Front View onto the top-left area of the   
sheet. 
* Drag downward from the Front View to project the Top View, and drag diagonally to 
place the Isometric View on the right side. 
*Use the Model Items / Smart Dimension tool to add all dimensions (30 mm and 2 
mm) as shown in the reference drawing. 
* Edit the Title Block to enter your details and title .

Step5:Generate 3D Documentation  
*Complete the 3D model. 
*Save the design. 
*Open the Drawing workspace. 
*Select Drawing from Design. 
*Choose the required sheet size  
*Place the Top View. 
*Add all necessary dimensions.
